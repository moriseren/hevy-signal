PRIVACY & DATA

Your training data stays local.

Hevy Signal stores synced routines, workout history, exercise mappings, and API keys on this computer. It contacts Hevy only when you test or sync. ChatGPT handoff creates a local text brief and does not contact OpenAI.

ABOUT

This public beta is unsigned. It does not install a background service, contact OpenAI, or require an OpenAI API key. CSV imports are parsed locally and are not uploaded to a Hevy Signal server.
