Hevy Signal — repair desktop exercise mappings

Repairs recognized Unmapped entries in an existing exercise-mappings JSON export. Your workout data and exercise names are processed on this device. No network API requests are made by this repair tool.

1. Export mappings from the Mac app

Open Hevy Signal → Privacy & Data → Export exercise mappings. Keep the original export as a backup.

2. Select your export

This page only changes entries whose major contributors are empty or labeled “Unmapped.” It never replaces an existing muscle classification.

3. Review and save

Choose the export file to start.

Return to Hevy Signal → Privacy & Data → Import exercise mappings and choose your repaired JSON. The app imports mappings only for matching exercise identifiers. Review any estimated mappings in its Exercise setup screen.

Hevy Signal source · Exercise classifications not matched to a verified reference are labeled heuristic estimates.
